
## About
this is a simple Quran Reading App made with Nuxt3+ it combine different tech such as:
PWA, Service Workers Web Workers, Pinia Store, Vuetify and more.
Feel free to open issue/suggestion or send PR or use the project your self.


Web App: al-kitab.pages.dev


Thanks to alquran.cloud for providing the surahs api

## Development
clone this repo and run

```bash
pnpm i
pnpm run dev
```
